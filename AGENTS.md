# homelab agent instructions

- homelab prose `MUST` go in `README.md`
- host specific information `MUST` go in `hosts/<host>/README.md`
- rfcs `MUST` go in `rfcs/NNNN-slug.md`, and `MUST` be derived from
  `rfcs/0000-template.md`
- before a change is accepted, an rfc `MUST` be `aligned` on `main` that covers
  its scope and correctness. when no rfcs cover the change, an rfc alignment PR
  `MUST` be submitted, approved, and merged before the original `MAY` merge.
